TÜRKÇE YAMALAR v21 - HABERLER / APK'LAR / ANIIMO V5

Yayınlama: ZIP'i açıp İÇİNDEKİ dosyaları GitHub deposunun en üst dizinine yükleyin. ZIP'in kendisini depoya koymak siteyi güncellemez. Eski dosyaların üzerine yazın; yeni apklar.html, aniimo-apk.html, apklar.js, apklar-veri.js ve functions/api/haberler.js dosyalarını da ekleyin. Cloudflare Pages Git bağlantısının yeni commit'i yayımlamasını bekleyin.

Haberler: /api/haberler uç noktası Steam duyurularını dört ilgili oyundan alır, 15 dakika önbellekte tutar. Kaynak erişilemezse sayfadaki yerel haberler görünür. Yakında çıkacak oyunlar için Steam takvimi bağlantısı eklendi. Cloudflare Pages panelinden ZIP sürükle-bırak ile dağıtımda functions klasörü çalışmaz; Git bağlantısıyla yayımlayın.

Mobil: Aniimo Türkçe APK hazır olunca doğrulanmış HTTPS indirme bağlantısını apklar-veri.js içindeki aniimo alanına girin. O zamana kadar indirme düğmesi pasiftir; siteye henüz çevrilmemiş paketi yüklemeyin.

PC: Aniimo v5 için kullanıcının sağladığı GoFile bağlantısı eklendi. Eski v4 indirmeleri eski sürüm olarak etiketli.
